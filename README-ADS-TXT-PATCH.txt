Witney Wire ads.txt patch for Google AdSense

What this patch adds
- Adds the required ads.txt file for Google AdSense at the website root.

File added
- ads.txt

The file contains:
google.com, pub-9678324763933867, DIRECT, f08c47fec0942fa0

After upload/deploy, check this URL:
https://witneywire.co.uk/ads.txt

If it is working, that page should show the single Google line above.
AdSense may still take some time to update the Ads.txt status after the file is live.
