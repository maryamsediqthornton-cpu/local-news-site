Witney Wire tractor road run article patch

What this patch adds
- A new News article about the Witney Tractor Road Run in support of Antics Charity.
- The article is written in past tense because the event has already happened.
- Matt's phone number has not been included.
- A landscape-safe hero image has been created from the supplied tractor photo so it displays properly on the article page.
- Both supplied photos are also included in the assets folder for future use.

- Category: news
- Headline: Tractors took to roads near Witney for charity road run
- URL: /article?id=witney-tractor-road-run-antics-charity

Files included
- articles.json and mirrored article JSON copies

- assets/witney-tractor-road-run-charity-hero.jpg

How to apply
1. Extract this ZIP.
2. Copy the included files into your latest local-news-site folder.
3. Replace the existing files when prompted.
4. Commit in GitHub Desktop.
5. Push origin and allow Cloudflare Pages to deploy.
6. Hard refresh the homepage/article page with Ctrl + F5.
